# GrazySAI

[English](README.md) | **Русский**

**Бесплатная программа для рисования и анимации: ощущение и кисти — как в PaintTool SAI 2.**
Работает в Windows и Linux (и FreeBSD), дружит с графическими планшетами и открывает файлы
`.sai2`. Версия 1.4.5.

![GrazySAI: окно рисования с навигатором, цветовым кругом, слоями и инструментами](docs/screenshot.png)

## Попробовать за минуту

1. Откройте страницу [**Releases**](https://github.com/grazyping/GrazySAI/releases/latest) и скачайте архив для своей системы.
2. Распакуйте и запустите программу. Устанавливать ничего не нужно.
   - **Windows**: `GrazySAI-…-windows-x86_64.zip` → `GrazySAI.exe` (для Windows 7 и 8 есть свой архив).
   - **Linux**: `GrazySAI-…-linux-x86_64.tar.gz` → `./GrazySAI`.
   - **FreeBSD**: пакет `.pkg` или архив.
3. Рисуйте. Чтобы открыть рисунок, перетащите файл в окно.

Программа сама обновляется с GitHub: когда выходит новая версия, в строке меню появляется
тихое уведомление. Интерфейс на 10 языках, свой язык выбирается автоматически.

## Что можно делать

**Рисовать**
- Кисти, которые ведут себя как в SAI: карандаш, аэрограф, кисть, акварель, маркер, ластик. Они
  смешивают краску с холстом: смешивание, разбавление, стойкость. Стабилизатор для ровных линий.
- Слои с папками, прикреплением, масками, все 28 режимов наложения, бумага, эффекты слоя
  («Кайма», «Двухцветный») и стили слоя (обводка, тень, свечение).
- Выделение (прямоугольник, лассо, волшебная палочка), трансформация, заливка, фильтры,
  линейки (прямая, эллипс), кривые и фигуры на слоях контура, текстовые слои.
- Библиотека кистей со своими формами и текстурами; кисти SAI 2, Photoshop, Krita и Clip Studio
  можно ввезти. Отдельная программа **мастерская кистей** (`GrazySAI-Studio`) помогает делать
  кисти и плагины.

**Анимировать**
- Таймлайн с папками анимации и кадрами (cel), Onion skin, просмотр и вывод в GIF, APNG,
  PNG-кадры и MP4.
- **Марионетка** как в After Effects: закрепите картинку булавками и потяните — вся сетка
  следует за ними. У булавок есть ключи на таймлайне.

**Работать с 3D**
- Слои 3D из моделей glTF, VRM, OBJ, FBX, PMX и COLLADA: позы, камера и перевод в линии для
  обводки.

**Настроить окно под себя**
- Панели, которые стыкуются как в Clip Studio («Окно → Стыкуемые панели»), рабочие пространства,
  поиск команд (Ctrl+Shift+P), панель быстрого доступа, свои сочетания клавиш и кнопки пера,
  автодействия (записать цепочку команд и повторять одной кнопкой).

**Обмениваться файлами**
- Читает и пишет `.sai2` (SAI 2 такие файлы тоже открывает), PSD и PSB со слоями, OpenRaster,
  PNG, JPEG, WebP, TIFF, BMP, TGA и QOI.
- **GrazySAI Convert** (`GrazySAI-Convert`) переводит целые пачки рисунков и моделей 3D из
  формата в формат.

**Планшеты**: нажим, наклон и поворот пера работают в Linux (XInput 2) и Windows (Windows Ink,
WinTab). Для проверок без планшета есть виртуальное перо и виртуальный планшет.

## Сборка из исходников

```bash
cargo build --release -p paint-app      # редактор: target/release/GrazySAI [файл.sai2]
cargo build --release -p paint-studio   # мастерская кистей
cargo build --release -p paint-convert  # конвертер
cargo build --release -p paint-cli      # командная строка: сверки, рендер, разбор .sai2
cargo test --workspace --release
```

Сборка под Windows с Linux: цель `x86_64-pc-windows-gnullvm`, компоновщик llvm-mingw
(путь — в `.cargo/config.toml`, поправить под свою машину).

Тесты по файлам пользователя ищут образцы в `~/SAI2` (или в `SAI2_SAMPLES`); если их нет, эти
тесты пропускаются.

## Переводы

Каждый язык — простой текстовый файл `crates/paint-app/lang/<код>.txt` со строками
`русский текст = перевод`; `{0}`, `{1}` — подставляемые программой значения. Тест
`every_key_is_translated` (`cargo test -p paint-app`) проверяет, что у каждой строки интерфейса
есть перевод во всех файлах. Исправления и новые языки приветствуются.

## Устройство

| Каталог | Что |
|---|---|
| `crates/paint-core` | Пиксели, плитки, слои, наложение, движок кисти, штрих, векторные фигуры, пересэмплирование, анимация, марионетка |
| `crates/paint-formats` | Чтение и запись `.sai2`, PSD, OpenRaster и картинок; общая таблица форматов |
| `crates/paint-app` | Окно редактора (egui), переводы в `lang/` |
| `crates/paint-3d` | Модели 3D: чтение, позы, отрисовка, вывод в GLB и OBJ |
| `crates/paint-studio` | Мастерская кистей и плагинов |
| `crates/paint-convert` | Конвертер пачками |
| `crates/paint-cli` | Командная строка для сверок с образцом |
| `crates/pen-test` | Журнал событий пера (Windows Ink, WinTab, XInput 2) |
| `crates/virtual-tablet` | Виртуальный планшет через `/dev/uinput` (Linux) |
| `docs/` | План, формат `.sai2`, правила программы своими словами, сверки, интерфейс |
| `tools/` | Выпуск, проверки на скрытом экране, виртуальное перо |
