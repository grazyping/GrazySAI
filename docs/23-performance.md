# Скорость на больших холстах

15 октября 2026. Замер на рисунке пользователя `YCH JimTheDoggo1.sai2`: 2300×4096, 191 слой,
204 МБ, на рабочей машине (все ядра).

| Что | Было | Стало |
|---|---|---|
| Чтение `.sai2` | 2,4 с | 0,3 с |
| Запись `.sai2` | 3,9 с | 3,1 с |
| Пересохранение целиком (`paint-cli resave`, со сверкой сведения) | 10,5 с | 4,2 с |
| Показ холста целиком после открытия | — | 0,3 с |

Что сделано:
- пиксели слоёв раскодируются параллельно, у каждого потока свой дескриптор файла
  (`sai2_doc::load`);
- сведённая картинка считается полосами по высоте плитки на всех ядрах (`Document::flatten`) —
  быстрее запись `.sai2` (блок `intg`) и экспорт;
- плитки на экране рисуются пачками на всех ядрах (`render_pending`);
- запись пикселей слоёв и раньше шла параллельно.

Память при чтении этого файла — около 1,3 ГБ (пиксели хранятся по 15 бит на канал в плитках
64×64; пустые плитки места не занимают).

Замер в окне: `PAINT_TIMING=1 SOsai файл.sai2` печатает, за сколько холст показан целиком.

Что ещё можно ускорить: кодирование сведённой картинки при записи (в один поток), историю отмены
на диске (сейчас каждая запись истории — копии плиток в памяти).

## Кисть большого размера (0.8.1)

Жалоба пользователя: Карандаш размером 350 — линия появлялась через 5–10 с.

Причина. Самая жёсткая ступень от 20 px ставит отпечатки через 0,85 px, как SAI. При размере 350
это ~1200 отпечатков на 1000 px линии, по ~120 тысяч точек каждый. Для каждой точки искалась
плитка в хеш-таблице, считались корень и степень профиля края.

Что сделано (результат тот же бит в бит — проверено отпечатками результата до и после):

- отпечаток обходится по плиткам: плитка ищется один раз, а не для каждой точки;
- строки обходятся только внутри круга отпечатка;
- внутри круга постоянного покрытия не считаются ни корень, ни профиль;
- точки, уже набравшие плотность отпечатка, пропускаются сразу;
- отпечатки одного движения пера раскладываются по плиткам и считаются на всех ядрах. Каждая
  плитка получает свои отпечатки в прежнем порядке.
- Кисть и Акварель: средний цвет под пачкой считается по плоской сетке, а не по хеш-набору
  точек. Краска кладётся по плиткам параллельно. Размытие Акварели идёт по строкам и полосам
  столбцов на всех ядрах, а буфер копии слоя переиспользуется.

| Линия 1000 px | Было | Стало |
|---|---|---|
| Карандаш 350 | 4,5 с | 0,12 с |
| Карандаш 100 | 0,39 с | 0,05 с |
| Кисть 350 | 13,7 с | 1,0 с |
| Акварель 350 | 40 с | 7,4 с |
| Акварель 100 | — | 0,7 с |

Тесты: `big_pencil_speed`, `big_mixing_speed` (замеры, `--ignored`), `mixing_brushes_fingerprint`,
`mixing_brushes_fingerprint_large`, `parallel_blur_is_bit_exact` (неизменность результата).

Акварель крупного размера остаётся медленной: размытие идёт по самому слою с радиусом,
умноженным на масштаб уровня. SAI размывает уменьшенную копию слоя (до 1/8), это в десятки раз
дешевле. Перейти на такую копию — задача в дорожной карте.
