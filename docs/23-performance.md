# Скорость на больших холстах

15 октября 2026. Замер на рисунке пользователя `YCH JimTheDoggo1.sai2`: 2300×4096, 191 слой,
204 МБ, на рабочей машине (все ядра).

| Что | Было | Стало |
|---|---|---|
| Чтение `.sai2` | 2,4 с | 0,3 с |
| Запись `.sai2` | 3,9 с | 3,1 с |
| Пересохранение целиком (`paint-cli resave`, со сверкой сведения) | 10,5 с | 4,2 с |
| Показ холста целиком после открытия | — | 0,3 с |

Что сделано:
- пиксели слоёв раскодируются параллельно, у каждого потока свой дескриптор файла
  (`sai2_doc::load`);
- сведённая картинка считается полосами по высоте плитки на всех ядрах (`Document::flatten`) —
  быстрее запись `.sai2` (блок `intg`) и экспорт;
- плитки на экране рисуются пачками на всех ядрах (`render_pending`);
- запись пикселей слоёв и раньше шла параллельно.

Память при чтении этого файла — около 1,3 ГБ (пиксели хранятся по 15 бит на канал в плитках
64×64; пустые плитки места не занимают).

Замер в окне: `PAINT_TIMING=1 SOsai файл.sai2` печатает, за сколько холст показан целиком.

Что ещё можно ускорить: кодирование сведённой картинки при записи (в один поток), историю отмены
на диске (сейчас каждая запись истории — копии плиток в памяти).
