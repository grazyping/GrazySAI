# Плагины GrazySAI: как написать свой

Плагин — небольшая программа на языке **Luau** (вариант Lua), которая добавляет команды в меню
«Плагины» и меняет открытый рисунок. Писать можно в любом текстовом редакторе, компилятор не нужен.
Примеры — в папке [`plugins/examples/`](../plugins/examples/).

Удобнее всего писать плагин в мастерской **GrazySAI Studio** (вкладка «Плагин»): там есть заготовки,
проверка на пробной картинке с ошибками по строкам и кнопка «Экспорт в GrazySAI» — плагин сразу
появляется в меню открытой рисовалки. Ниже — как то же сделать вручную.

## Первый плагин за 10 минут

1. Сделайте папку с двумя файлами.

   `plugin.txt`:

   ```
   id=myname.brighten
   name=Светлее
   version=1.0
   author=Я
   description=Делает слой светлее.
   api=1
   command.0.menu=Мои/Светлее
   command.0.function=brighten
   command.0.param.0=amount slider 0 100 1 30 Насколько, %
   ```

   `main.lua`:

   ```lua
   function brighten(p)
     local k = p.amount / 100
     canvas.map(function(r, g, b, a)
       return r + (255 - r) * k, g + (255 - g) * k, b + (255 - b) * k
     end)
   end
   ```

2. Запакуйте оба файла в zip (без папки внутри) и переименуйте его в `светлее.gsplugin`.
3. В GrazySAI: «Файл → Открыть» этот файл (или перетащите его в окно) → «Установить».
4. «Плагины → Мои → Светлее» — откроется окно с ползунком «Насколько, %», затем «ОК».

Ошибка в коде показывается в строке состояния и в окне «Плагины → Управление плагинами…» с номером
строки, например `myname.brighten/main.lua:3: attempt to index nil`.

## `plugin.txt`

Текст по строке `ключ=значение`; строки с `#` в начале — пояснения.

| Ключ | Что это |
|---|---|
| `id` | имя плагина латиницей, цифрами и `._-`, лучше «автор.плагин»; по нему плагин заменяется при новой версии |
| `name`, `version`, `author`, `description` | показываются при установке и в окне «Плагины» |
| `api` | версия API (сейчас `1`); плагин с большей версией старая программа не запустит |
| `command.N.menu` | путь в меню «Плагины»: `Подменю/Команда` (команды разных плагинов с одним подменю — вместе) |
| `command.N.function` | имя функции в `main.lua`, которая выполняется по команде |
| `command.N.param.M` | поле окна параметров (см. ниже); без полей команда выполняется сразу |

Команды нумеруются с 0 подряд (до 64), поля — тоже с 0 (до 32).

Поля:

| Вид | Запись | Значение в функции |
|---|---|---|
| ползунок | `id slider мин макс шаг по_умолчанию Подпись` | число (шаг 1 — целое) |
| флажок | `id check 0_или_1 Подпись` | `0` или `1` |
| выбор | `id choice номер Вариант1\|Вариант2\|… Подпись` | номер варианта с 0 |

Функция получает таблицу значений: `p.amount`, `p.mode` …

## API

Плагин видит только эти функции и безопасную часть стандартной библиотеки Luau (`math`, `string`,
`table`, `utf8`, `bit32`). Цвета — числа 0..255, без предумножения на прозрачность; координаты —
пиксели холста, (0, 0) — левый верхний угол.

| Функция | Что делает |
|---|---|
| `canvas.width()`, `canvas.height()` | размер холста |
| `canvas.get(x, y)` → `r, g, b, a` | точка текущего слоя (за краем — 0, 0, 0, 0) |
| `canvas.set(x, y, r, g, b[, a])` | поставить точку (a по умолчанию 255); дробные значения округляются, лишнее обрезается до 0..255 |
| `canvas.map(f[, x0, y0, x1, y1])` | для каждой точки рамки вызвать `f(r, g, b, a, x, y)`, записать то, что она вернула (`r, g, b[, a]`); рамка по умолчанию — выделение, без него — весь холст. Быстрее, чем `get`/`set` по одной |
| `canvas.selection()` → `x0, y0, x1, y1` или `nil` | рамка выделения (правая и нижняя граница не входят) |
| `canvas.selected(x, y)` → 0..1 | насколько точка выделена (без выделения — 1) |
| `canvas.bounds()` → `x0, y0, x1, y1` или `nil` | рамка непустых точек слоя |
| `canvas.new_layer([имя])` | новый слой над текущим; дальше `get`/`set`/`map` работают с ним |
| `color.get()` → `r, g, b` | основной цвет |
| `color.set(r, g, b)` | поменять основной цвет |
| `log(…)` | строка в журнал окна «Плагины» (до 1000 строк за запуск) |

Плагин работает с текущим слоем, если это обычный слой (не папка и не слой контура).

## Своя динамика кисти

Плагин может дать кистям свою динамику — функцию, которая вызывается на каждый отпечаток мазка.
В `plugin.txt`:

```
dynamics.0.name=Дрожь
dynamics.0.function=jitter
```

В `main.lua`:

```lua
function jitter(i)
  return { size = 0.6 + i.random * 0.6, angle = (i.random2 - 0.5) * 120, scatter = (i.random - 0.5) * 0.8 }
end
```

| Вход (`i.…`) | Что это |
|---|---|
| `pressure` | нажим 0..1 |
| `speed` | путь пера за одно событие ввода, px |
| `direction` | направление мазка 0..1 (0 — вправо, 0,25 — вниз) |
| `distance` | путь от начала мазка, px |
| `random`, `random2` | два случайных числа 0..1 на отпечаток (мазок повторяется одинаково) |

| Выход | Что это |
|---|---|
| `size`, `density`, `ratio` | множители размера, плотности и толщины отпечатка |
| `angle` | поворот отпечатка, градусы |
| `scatter` | сдвиг поперёк мазка в долях диаметра (со знаком) |

Чего нет в ответе — не меняется. Выбрать динамику: настройки кисти → «Динамика» → «Из плагина»
(в рисовалке и в мастерской); выбор сохраняется в кисти (`dyn_plugin=id/имя` в `brush.txt`) и
работает поверх связей «вход → кривая → параметр». В пакете могут быть только динамики, без команд.
Вызов стоит доли микросекунды; на мазок — свой экземпляр песочницы (до 10 с и 64 МБ); после ошибки
динамика выключается до конца мазка, ошибка — в строке состояния и журнале.

## Что плагину нельзя

Код выполняется в песочнице:

- нет доступа к файлам, сети, системе, другим программам (`io`, `os`, `debug`, `require`,
  `dofile`, `load` отсутствуют);
- общие таблицы (`math`, `string` …) только для чтения;
- память — до 256 МБ, время — до 60 секунд, потом плагин останавливается;
- каждый запуск — с чистого листа: плагин не хранит ничего между запусками.

Всё, что плагин сделал с рисунком, отменяется («Правка → Отменить»): изменения каждого слоя —
одним шагом, новый слой — ещё одним.

## Скорость

Luau — язык-интерпретатор: около миллиона точек в секунду через `canvas.map`. Для фильтров на весь
большой холст это секунды; тяжёлые фильтры пишутся на WebAssembly (ниже).

## Фильтры на WebAssembly

Для работы с каждой точкой (размытия, свёртки, свои эффекты) команда может быть модулем
WebAssembly — его собирают из Rust, C, Zig и других языков. Программа режет область (выделение или
весь холст) на плитки 256×256, обрабатывает их одновременно в нескольких потоках и смешивает
результат с исходным по выделению. Пример с исходником на Rust — [`plugins/examples/wasm-blur/`](../plugins/examples/wasm-blur/)
(размытие 1200×900 — около 0,2 с).

В `plugin.txt`:

```
command.0.menu=Мои/Размытие
command.0.function=blur        # имя функции в модуле
command.0.wasm=filter.wasm     # файл модуля в пакете
command.0.margin=32            # поля вокруг плитки (соседние точки), 0..64
command.0.param.0=radius slider 1 32 1 6 Радиус, px
```

Модуль экспортирует:

| Экспорт | Что делает |
|---|---|
| `memory` | память модуля |
| `gs_alloc(байты: u32) -> u32` | выделить память; программа вызывает один раз на поток и кладёт туда плитку и параметры |
| `имя(пиксели: u32, ширина: u32, высота: u32, параметры: u32, число: u32)` | обработать плитку на месте: RGBA по 8 бит без предумножения, построчно; параметры — массив f64 в порядке полей команды |

Плитка приходит с полями (`margin`) со всех сторон, где они есть на холсте; обратно берётся только
внутренняя часть — поэтому фильтр с соседями не даёт швов. Импортов у модуля быть не должно (никаких
функций программы, файлов и сети), память — до 256 МБ, число шагов на плитку ограничено: зациклившийся
модуль останавливается.

Сборка примера на Rust:

```
rustup target add wasm32-unknown-unknown
cargo build --release --target wasm32-unknown-unknown
cp target/wasm32-unknown-unknown/release/gs_blur.wasm filter.wasm
```

В мастерской: вкладка «Плагин» → «Добавить .wasm…» (или перетащить файл `.wasm` в окно) — модуль
попадёт в пакет при сохранении и экспорте; «▶ Проверить» работает и для фильтров на WebAssembly.

## Проверка и обновление

- Плагины лежат в папке настроек, `plugins/` (кнопка «Плагины → Открыть папку плагинов»).
- Пакет из папки `plugins/dev/` заменяет установленный с тем же `id` и подхватывается на лету,
  когда меняется файл-отметка `plugins/dev/.changed`; так с плагином будет работать мастерская
  GrazySAI Studio.
- Новая версия: поднимите `version` и установите пакет ещё раз — он заменит прежний.
