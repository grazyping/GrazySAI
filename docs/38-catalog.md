# Каталог кистей и плагинов: формат для тех, кто захочет его сделать

Сами мы общий каталог не ведём. Но формат открыт: кто угодно может выложить свой каталог на любом
сайте или в репозитории (GitHub, GitLab, свой сервер), а пользователи — скачать оттуда файлы и
открыть их в GrazySAI (`.gsbrush`, `.gsbrushes`, `.gsplugin` ставятся через «Файл → Открыть» или
перетаскиванием).

## Список `index.json`

```json
{
  "format": 1,
  "name": "Каталог Васи",
  "items": [
    {
      "id": "vasya.chalk",
      "kind": "brush",
      "name": "Мел",
      "version": "1.2",
      "author": "Вася",
      "description": "Мел с рваным краем",
      "url": "https://example.org/files/chalk.gsbrush",
      "sha256": "9f2c…",
      "size": 48213,
      "preview": "https://example.org/files/chalk.png",
      "license": "CC0-1.0"
    }
  ]
}
```

| Поле | Что это |
|---|---|
| `id` | уникальное имя: у плагина — тот же `id`, что в `plugin.txt` |
| `kind` | `brush` (`.gsbrush`), `brushset` (`.gsbrushes`), `plugin` (`.gsplugin`) |
| `name`, `version`, `author`, `description` | для показа |
| `url` | прямая ссылка на файл (HTTPS) |
| `sha256`, `size` | контрольная сумма и размер файла: программа или человек проверяет скачанное |
| `preview` | картинка (у кисти — `preview.png` из её же файла) |
| `license` | лицензия файла (SPDX: `CC0-1.0`, `CC-BY-4.0`, `MIT`…) |

## Если каталог — репозиторий на GitHub

Бесплатный способ без своего сервера: репозиторий с `index.json`, сами файлы — в его Releases. Автор
добавляет свою кисть запросом на слияние (файл в Releases, строка в `index.json`), хозяин каталога
проверяет и принимает. Ссылка вида
`https://github.com/<хозяин>/<каталог>/releases/download/<версия>/<файл>`.

## Безопасность

Плагины работают в песочнице (`docs/36-plugins.md`), файлы кистей — только данные, но всё равно:
скачивайте по HTTPS, сверяйте `sha256`, ставьте плагины от тех, кому доверяете. Программа показывает
описание плагина перед установкой.
