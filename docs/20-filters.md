# Фильтры

15 октября 2026. Код — `paint-core/src/filters.rs`; окно — меню «Фильтр» (Ctrl+U — «Тон и
насыщенность»). Правила прочитаны в коде SAI 2017 (своими словами ниже) и сверены с живой SAI.

Цветовые фильтры считают по прямому (не предумноженному) цвету каждой точки, альфа не меняется;
результат ограничен 0…1. С выделением результат смешивается с исходным по доле выделения. Окно
показывает предпросмотр на холсте; OK — одна запись истории, «Отмена» и Ctrl+Z — вернуть.

## Яркость и контраст (три ползунка −100…100, делятся на 100)

- **Яркость b**: при b ≥ 0 канал `x + x·b² + b²` (к белому), при b < 0 — `x − (1 − x)·b² − b²`.
- **Глубина d**: при d ≥ 0 канал сдвигается к `x²/max` на долю `4d²` (краски ярче, тёмные
  каналы темнее); при d < 0 — к яркости `0,299R + 0,587G + 0,114B` на долю `|d|`.
- **Контраст k**: `(x − 0,5)·K + 0,5`, где `K = 1 + 4k²` при k ≥ 0 и `1 + k` при k < 0.

Сверено: чёрная линия с альфой 0,565 поверх белого при яркости +51 — у SAI 149, у нас 148,5.

## Тон и насыщенность (тон −180…180 делится на 60, насыщенность и яркость −100…100 — на 100)

Цвет раскладывается на тон (в шестых долях круга, наибольший канал при равенстве — R, затем G),
«размах» C = max − min и «сумму» L = max + min.

- **Тон**: прибавляется, по кругу.
- **Яркость l**: при l ≥ 0 `L += (2 − L)·l`, `C −= C·l`; при l < 0 `L += L·l`, `C += C·l`.
- **Насыщенность s**: при s < 0 `C += C·s`. При s ≥ 0 размах растёт к наибольшему возможному при
  этой яркости (`L` или `2 − L`) с весом `((t − s)(1 − g) + s)·min(1, 128C)`, где
  `w = (1 − C)⁴`, `t = min(1, (1,2w + 1)·s·(1 − w))`, `g = (5·max(s − 0,8, 0))³` — уже яркие
  цвета насыщаются бережнее.
- Цвет собирается обратно по сектору тона: наибольший канал `(C + L)/2`, остальные — на `C` ниже
  или по доле внутри сектора.
- **Окрасить**: тон задаётся ползунком, насыщенность `(s + 1)/2`, середина `(max + min)/2`
  двигается яркостью; как HSL с заданными тоном и насыщенностью.

## Размытие по Гауссу (радиус 0,1…40)

Гауссово ядро с σ = радиусу, два прохода (строки, столбцы) по предумноженным значениям, за краем —
прозрачность. Сверено по сечению чёрной линии в живой SAI: радиусы 1,0 / 3,0 / 9,9 — разница
не больше 2 / 1 / 0 уровней (`tests/filters_live.rs`). В коде SAI само ядро размытия не найдено,
правило получено измерением. Считается только рамка содержимого с запасом 3σ, на всех ядрах.

## Как снималось

SAI 2017 на скрытом экране (Xvfb) — клавиши без оконного менеджера туда не доходят, поэтому всё
мышью: меню, пункты, ползунки (щелчок по ползунку ставит значение; видно на снимке окна). Вставка
картинки и «холст из буфера» в ограниченном режиме выключены — проверочную линию рисовали
карандашом в самой SAI.

## Резкость (0.8.31, как в Clip Studio Paint)

Своих фильтров резкости у SAI 2017 нет (пункты меню не работают), поэтому они сделаны по
описанию Clip Studio Paint; точной сверки нет — код CSP закрыт.

- «Резкость» и «Сильная резкость» — свёртка крестом 3×3: центр `1 + 4s`, соседи `−s`,
  s = 0,5 и 1, по предумноженным каналам; на краю холста точки повторяются.
- «Нерезкая маска» — `точка + сила·(точка − размытая по Гауссу с σ = радиус)` там, где
  наибольшая разница каналов больше порога (0–255); сила 1–500 %.
- Выделение учитывается, как у остальных фильтров. Тесты `sharpen_raises_contrast_at_the_edge_only`,
  `unsharp_threshold_keeps_small_differences`.

## Коррекция (0.8.32, как в Clip Studio Paint)

- «Изменение толщины линий»: `n` шагов (1–20); шаг берёт у точки и её соседей самую
  непрозрачную (утолщить) или самую прозрачную (сузить) точку целиком, шаги по очереди квадратом
  3×3 и крестом — как расширение выделения SAI, поэтому углы срезаются под 45°.
- «Удаление пыли»: связные по 8 соседям пятна площадью не больше «Размера пыли» (точек): на
  прозрачном — стираются; небелые на белом (каналы ≥ 240 — белое) — белеют; прозрачные дырки
  (не у края холста) — заливаются средним цветом соседей или основным цветом.
- Тест `line_width_and_dust`.

## Эффекты и отрисовка (0.8.33, как в Clip Studio Paint)

- «Хроматическая аберрация»: красный берётся со сдвигом −d, синий +d (по кругу — от середины
  холста пропорционально расстоянию, сдвигом — вдоль угла); за краем холста — край; непрозрачность
  — наибольшая из трёх.
- «Шум»: ±сила/2 к каждой точке (серый — одинаково по каналам), постоянный по координатам
  (предпросмотр не мерцает), альфа не меняется.
- «Мозаика»: квадраты от угла холста, среднее по квадрату.
- «Кристаллизация»: ячейки Вороного вокруг точек сетки со сдвигом «разброс», цвет — среднее по
  ячейке; «бесшовно» — сетка замыкается по краям холста.
- «Ретро-плёнка»: тон пресета (винтаж — выцветание, современный — холоднее, тёплый), сепия,
  оранжевая засветка от левого верхнего угла, шум и лёгкая аберрация по кругу.
- «Шум Перлина»: градиентный шум с плавной кривой 6t⁵ − 15t⁴ + 10t³, октавы удваивают частоту и
  ослабляются на «ослабление»; серый непрозрачный узор заменяет содержимое слоя.
- Тест `effects_do_what_they_say`; картинки для глаза — `tests/filters_look.rs`
  (`SOSAI_FILTERS_OUT`).

## Размытие (0.8.34, как в Clip Studio Paint)

- «Среднее»: весь слой (или выделение) — один средний цвет непрозрачных точек.
- «Размытие» и «Сильное размытие»: квадратное окно радиусом 1 и 2, два прохода (почти гаусс).
- «Размытие в движении»: среднее вдоль отрезка длиной «сила» под углом; направление — в обе
  стороны, вперёд или назад; «Плавно» — веса треугольником, а не поровну.
- «Радиальное размытие»: отрезок вдоль луча от центра содержимого слоя, длина растёт с
  расстоянием (наружу, внутрь или в обе стороны).
- «Размытие вращением»: дуга вокруг центра содержимого на заданный угол, по или против часовой.
- «Сглаживание краёв»: ядро 3×3 [1,2,1] только там, где соседи различаются больше чем на 0,25 —
  ровные заливки не трогаются.
- «Размытие линзы»: диск (круг или многоугольник 3–8 углов) через суммы по строкам; перед
  усреднением цвет возводится в степень 1 + 2·«яркость бликов», после — обратно, поэтому яркие
  точки разливаются в заметные блики (боке).
- За краем холста берётся край; альфа размывается вместе с цветом (предумноженно).
- Тест `blurs_spread_and_keep_flat_areas`.

## Искажение (0.8.35, как в Clip Studio Paint)

Каждая точка холста берётся из другого места слоя (обратное отображение, двулинейная выборка;
за краем холста — край). Середина задаётся ползунками X/Y (по умолчанию середина холста), радиус
— у щипка, ряби, «рыбьего глаза» и скручивания; вне круга точки не трогаются.

- «Щипок»: r' = r·sin(π/2·t)^(−0,75·сила), t = r/радиус; плюс тянет к середине, минус выпячивает.
- «Рыбий глаз»: r' = r·(1 − s + s·t²) — середина увеличена в 1/(1 − s) раз, у края круга 1:1.
- «Скручивание»: поворот на угол·(1 − t)².
- «Рябь»: сдвиг вдоль луча на размах·sin(2πr/λ)·(1 − t), у середины первые полволны гаснут.
- «Волна»: сдвиг вдоль угла на размах·f(q/λ), q — координата поперёк сдвига; f — синус,
  треугольник или прямоугольник.
- «Полярные координаты»: верх прямоугольника — середина круга, ширина — оборот по часовой от
  12 часов, радиус круга — половина меньшей стороны холста; обратный режим — наоборот.
- Тест `distortions_move_points_and_keep_identity_at_zero`; картинки — `tests/filters_look.rs`.
