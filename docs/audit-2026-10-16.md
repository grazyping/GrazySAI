# Аудит кода GrazySAI, 16 октября 2026

Метод — навык `code-audit` (по OWASP Code Review Guide v2, приспособленному к настольной
программе на Rust): сначала поверхность атаки и риски, затем инструменты, затем ручная проверка
каждой находки. Версия — 0.9.12 и следующие исправления.

## Что защищаем и откуда приходят чужие данные

- **Рисунки пользователя.** Худшее — потерять работу: падение программы закрывает все вкладки с
  несохранённым.
- **Входы:** открываемые файлы (`.sai2`, PSD, ORA, PNG, JPEG, BMP, TGA, TIFF, WebP, QOI) —
  в том числе чужие и повреждённые; обозреватель файлов сам читает каждый файл папки ради
  миниатюры; буфер обмена; перетаскивание; файл настроек; ответ GitHub при обновлении.
- Самый большой риск — разбор файлов: он идёт без участия пользователя (миниатюры), а данные
  в нём — чужие.

## Инструменты

| Инструмент | Результат |
|---|---|
| `cargo audit` (RustSec, 1329 записей) | уязвимостей нет; 2 предупреждения: `paste` и `ttf-parser` больше не сопровождаются (обе — из egui 0.29) |
| `cargo deny check bans sources` | в порядке; 24 дубля версий (старые egui/winit) — только размер программы |
| Тест порчи файлов `robustness` (свой) | ~73 000 испорченных вариантов (обрезка, биты, 4-байтные поля), все форматы |
| `cargo-fuzz` (libFuzzer + AddressSanitizer) | 4 цели: `.sai2`, PSD, ORA, картинки; по 4 потока |
| Ручной просмотр | `unsafe`, `unwrap`/`expect`, потоки, кэши |

## Память программы в работе

Скрытый экран, холст 4096×4096, кисть 300 px (`RSS` процесса):

| Шаг | Память |
|---|---|
| запуск | 327 МБ |
| 40 мазков | 593 МБ (история отмены) |
| 5 кругов «отменить всё — вернуть всё» | 590–599 МБ — не растёт |
| 4 × 20 раз «Тон и насыщенность» → «Отмена» | 427 → 448 → 479 → 470 МБ — выходит на плато (запас распределителя памяти), не утечка |

Утечек не найдено. История отмены сверх своего бюджета уходит на диск (`history_disk`).

Фаззер — три круга по 10 минут на 16 ядрах (4 цели). После исправлений последний круг нашёл
только медленные под AddressSanitizer случаи: испорченный слой контура разбирается 0,4 с вместо
0,03 с (кривая упирается в предел 4 млн точек) — допустимо.

Каждое исправление закреплено: тест `robustness` гоняет порчи всех форматов, находки фаззера
сохраняются в `fuzz/artifacts/` (не в репозитории — там могут быть рисунки пользователя).

## Как повторить

```
cargo test --release -p paint-formats --test robustness -- --ignored --nocapture   # 300 порч на файл, ~40 с
GRAZYSAI_FUZZ_N=3000 GRAZYSAI_FUZZ_DIR=<копии образцов> cargo test …               # глубже
cargo +nightly fuzz run -O sai2 <набор> -- -rss_limit_mb=2048 -timeout=10 -jobs=4 -workers=4
cargo audit; cargo deny check bans sources
```
