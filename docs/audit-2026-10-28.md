# Аудит кода GrazySAI, 28 октября 2026

Четыре равные цели: убрать ошибки, убрать костыли, упростить код, ускорить тяжёлые операции. Версия —
1.4.1 и следующие правки (коммиты после метки `v1.4.1`). Метод — навык `code-audit`: сначала
инструменты и замеры, потом ручная проверка каждой находки. Каждое ускорение проверено отпечатком
результата: картинка до и после совпадает до бита, если не сказано иное.

Инструменты: rustc и cargo 1.99.0, clippy (с `pedantic` и `nursery` — только для разбора, не для
правок по всему коду), cargo-audit 0.22.2, cargo-fuzz (libFuzzer + AddressSanitizer), свой замер
`crates/paint-core/tests/speed_ops.rs`, проверка большого холста `crates/paint-formats/tests/huge_canvas.rs`,
скрытый экран (`tools/ui-check.sh`), самопроверка Windows-сборки под Wine, живая SAI 2 под Wine.

## 2. Костыли

| Что было | Что стало |
|---|---|
| Чтобы нарисовать одну панель (в отдельном окне, во вкладке, в колонке), `win.show` временно переписывался и возвращался. Из-за этого понадобилось ещё и откладывать сохранение настроек | какие части колонки рисовать — параметр `left_panel`/`right_panel`; отложенное сохранение осталось только для дерева вкладок (его egui_dock требует вынимать) |
| Потоки миниатюр обозревателя файлов проверяли очередь каждые 30 мс | ждут на условной переменной; при закрытии обозревателя флаг ставится под замком (без потерянного сигнала) |

| Окно программы не держало большие холсты (показ всего холста в полном разрешении: у 30000² — 3,6 ГБ памяти и столько же на видеокарте) | уровни детализации показа (ниже) |

Оставлено: опрос WinTab раз в 3 мс в `pen.rs` — менять без проверки на настоящем планшете под Windows
нельзя.

## 3. Упрощение и устройство

- Общие шаги фильтров «прочитать прямоугольник» и «записать обратно» шли по точке с поиском плитки в
  хеш-таблице на каждую — теперь строками плиток (`TileMap::read_rect`, `write_rect`) и по плиткам
  параллельно. Этим пользуются около десяти фильтров.
- Показ: экранная плитка 256×256 при уменьшении меньше 50 % хранит уменьшенную копию (до 1/64);
  прежний уровень показывается растянутым, пока новый не готов; плитки далеко от вида сверх 1536
  выбрасываются и пересчитываются, когда снова видны. Очередь, «удержание» картинки, проигрывание и
  навигатор остались на прежних ключах плиток холста. На 100 % показ совпадает попиксельно с прежним.
- `.sai2` пишет сведённую картинку и миниатюру полосами по 256 строк (байты файла те же, сверено с
  прежним кодером), одинаковые блоки кодируются один раз, блоки слоёв читаются прямо из плиток.
- Холст в окне программы — до 30000×30000; ядро, `.sai2` и конвертер — до 100000×100000, как у SAI 2.
  Действия, которым нужна вся картинка сразу, на холсте больше 30000² отказываются с сообщением.

## 4. Скорость

Холст 3840×2160, 16 потоков, `cargo test --release -p paint-core --test speed_ops -- --ignored --nocapture`.
«Было» — тот же замер на выпуске 1.4.1 (чистый прогон, без других задач); отпечатки результатов всех
13 операций у 1.4.1 и после правок одинаковы.

| Операция | 1.4.1 | Стало | Быстрее |
|---|---|---|---|
| Медиана r=3 | 6,83 с | 0,67 с | в 10 раз |
| Поворот 4K, Ланцош 3 | 5,74 с | 0,73 с | в 7,9 раза |
| Волшебная палочка | 0,80 с | 0,10 с | в 8 раз |
| Размытие по Гауссу r=40 | 3,82 с | 1,04 с | в 3,7 раза |
| Размытие линзы r=20 | 2,82 с | 1,09 с | в 2,6 раза |
| Нерезкая маска r=10 | 2,70 с | 1,05 с | в 2,6 раза |
| Растушёвка, мазок 300 px | 2,23 с | 0,95 с | в 2,3 раза |

Без изменений (их код не трогался): карандаш, кисть, акварель, заливка с «Закрыть щели», расширение
выделения, раскраска по контуру.

Большой холст (`huge_canvas`): сохранение `.sai2` 100000×100000 — 217 с → 19 с при 25–40 МБ памяти
(раньше падало); холст 30000² в окне «по окну» — 210 МБ, при 100 % с прокруткой — 320–370 МБ.

Простой программы: 88 с процессора за 10 с → 0,8 с (см. ошибку 4).

Не трогалось: сведение 4K (ускорено в 1.4.1) и решатель марионетки.

## SAI 2 и большие холсты (живая SAI 2 2026-07-02b под Wine)

Предел в SAI — 100000 точек по стороне (сообщение программы), но холст хранится целиком: пустой
10000×10000 — 1,1 ГБ (около 11 байт на точку). Холсты 13000², 20000², 30000², 50000² и 100000²
не создались («Canvas construction failed») при пике около 1,5 ГБ. По странице SAI лицензия снимает
только запрет на сохранение и открытие, о размере холста там ничего нет; проверить на настоящей
Windows ещё нужно. GrazySAI хранит холст разреженно (пустые плитки не занимают памяти).

## Что не проверено

- Всё это — на Linux и под Wine. На настоящей Windows (p3p5) — нет: показ с уровнями детализации,
  отдельные окна панелей, простой, большой холст.
- Отдельное окно панели после правки `win.show` на снимке не видно (Xvfb без оконного менеджера не
  отдаёт содержимое закрытого окна); главное окно и вкладки проверены.
- Самопроверка под Wine: 18 проверок прошли; «системные шрифты» — провал среды (в префиксе Wine нет
  папки шрифтов).

## Как повторить

```
cargo test --release -p paint-core --test speed_ops -- --ignored --nocapture
HUGE_SIDE=30000 cargo test --release -p paint-formats --test huge_canvas -- --ignored --nocapture --test-threads=1
cargo +nightly fuzz run -O model fuzz/corpus/model -- -rss_limit_mb=2048 -timeout=10 -jobs=8 -workers=8 -max_total_time=600
cargo audit
```
