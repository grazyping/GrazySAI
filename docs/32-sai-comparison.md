# Сравнение с SAI 2017: функция за функцией

Цель — чтобы GrazySAI работал как оригинал. Здесь каждая команда SAI 2 (сборка 2017-01-19,
полный перечень — `07-sai2-reference.md`, раздел 6) и как она сделана у нас. Обновляется при
каждой сверке; найденные расхождения идут в дорожную карту.

Обозначения: **✔** — есть и сверено с живой SAI (или с её кодом); **≈** — есть, но работает
иначе или не сверено; **✘** — нет. «Своё» — сверх SAI.

## Сверка 20.10.2026

Полный перечень записей меню из таблицы надписей SAI 2017 (177) против GrazySAI, плюс перечни
инструментов, режимов наложения, способов пересэмплирования, режимов рисования, эффектов слоя,
видов контура и направления щетины. Спорные записи проверены в живом меню образца и по
сохранённой декомпиляции (6107 функций, 14.10.2026).

| Итог | Записей меню |
|---|---|
| Есть в SAI 2017 и в GrazySAI | 140 |
| Заготовки SAI 2017 без пункта меню (перспективные сетки, нереализованные фильтры) | 31 |
| Служебные записи | 3 |
| У нас есть, в меню 2017 не видны (маска слоя) | 2 |
| **Нет в GrazySAI: экспорт `.psb`** | 1 |

- Инструменты: все 11 видов из меню создания инструмента SAI 2017 есть; Scatter Brush в 2017 —
  заготовка. Режимы наложения: все 28 из списка 2017 (сверены тестом). Пересэмплирование: все 5.
  Эффекты слоя «Кайма» и «Двухцветный», три вида контура, направление щетины — есть.
- Поведение против живой SAI закреплено тестами (кисти, давление, аэрограф, смешивание, текстура,
  размытие, яркость, пересэмплирование, режимы, эффекты, обводка, деформация, стабилизатор,
  история, формат `.sai2`). Проверка самих тестов намеренной порчей кода: формулу Screen и окно
  Lanczos тесты ловят; правило края тонких отпечатков (показатель 1,35) проходило в допуске
  1 уровень — для кистей до 5 px допуск теперь 0, порча ловится.
- Без автоматической сверки с образцом: «Тон/Насыщенность» (сверено вручную), волшебная палочка,
  заливка, градиент, расширение/сужение выделения. Подать в образец цветную картинку через
  буфер обмена не удалось (Wine не передал изображение) — нужен другой путь.
