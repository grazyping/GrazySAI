# Кисти Clip Studio Paint (`.sut`): можно ли подключить

Оценка 20.10.2026 по образцу кисти и открытым описаниям формата (их код не используется:
лицензии AGPL и CC BY-NC; ниже — своими словами).

## Как устроен файл

- `.sut` — обычная база SQLite. Таблицы: `Manager` (одна строка: тип инструмента, версия, общий
  график нажима), `Node` (имя кисти в дереве, значок, ссылки на соседей), `Variant` (сами настройки,
  187 полей), `MaterialFile` (вложенные картинки).
- `Variant` — именованные поля, многие прямо соответствуют нашим: `BrushSize` (px), `Opacity`,
  `BrushFlow`, `BrushHardness`, `BrushInterval` (шаг, %), `BrushThickness`, `BrushRotation`,
  `CompositeMode`, текстура (`TextureImage`, масштаб, поворот, плотность, контраст), смешивание
  (`BrushUseWaterColor`, `BrushMixColor`, `BrushMixAlpha`, `BrushBlur`), кайма акварели
  (`BrushWaterEdge*`), сглаживание (`BrushRevision`), нажим к концам (`BrushIn/OutLength`).
- Зависимость от нажима (`…Effector`) — двоичное поле: заголовок, флаги источника (нажим, наклон,
  скорость, случайно), нижняя граница и точки кривой.
- Картинки отпечатка и текстуры — в `MaterialFile.FileData`: tar-архив, внутри
  `data/material.layer` (собственный формат CSP, внутри — обычный PNG с прозрачностью),
  `icedata/layerData.xml` (метки: например `PaperTexture` — текстура бумаги) и миниатюра.
  Кисть ссылается на картинки списками в `BrushPatternImageArray` / `TextureImage`.

## Что ложится на движок GrazySAI

| CSP | GrazySAI |
|---|---|
| размер, непрозрачность, жёсткость | размер, плотность, жёсткость |
| нажим → размер / непрозрачность (кривая) | «Размер» / «Плотн.» от нажима, мин. размер |
| отпечаток из картинки (`BrushPatternImageArray`) | форма кисти из картинки |
| текстура (`TextureImage`, плотность, масштаб) | текстура кисти |
| смешивание цвета (`BrushMixColor`, `BrushMixAlpha`, `BrushBlur`) | Кисть / Акварель: смешивание, сохранение непрозрачности, размытие |
| кайма акварели | эффект «Кайма» (как приближение) |

Не ложится (при открытии сообщить, что пропущено): распыление (`BrushUseSpray`), двойная кисть
(`UseDualBrush`), изменение цвета по мазку (`BrushHueChange` и др.), ленточная кисть, векторные
поля, сужение по длине мазка (у нас — только от нажима).

## Вывод

Подключить можно: открыть `.sut` как набор кистей, взять основные настройки, картинку отпечатка и
текстуру; результат будет похож, но не равен CSP — у CSP другой движок. Нужны: чтение SQLite
(крейт `rusqlite` со встроенным SQLite — собирается и под Windows), разбор tar и поиск PNG внутри
`.layer`, разбор кривой нажима. Проверка — на кистях пользователя (образцы в репозиторий не
кладутся: у найденных открытых образцов лицензии не наши).
