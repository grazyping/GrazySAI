# Свои кисти для GrazySAI: как сделать и поделиться

Кисть — файл `.gsbrush` (одна кисть) или `.gsbrushes` (набор). Делать удобнее всего в мастерской
**GrazySAI Studio** — она лежит рядом с GrazySAI (`GrazySAI-Studio`, в Windows `GrazySAI-Studio.exe`).
Устройство файла — [docs/35-gsbrush-format.md](35-gsbrush-format.md).

## За 5 минут

1. Откройте GrazySAI и GrazySAI Studio одновременно.
2. В мастерской на вкладке «Кисть»: «Новая» → вид (карандаш, кисть, акварель…), имя.
3. «Отпечаток» → «Создать: брызги» (или «Добавить картинку…» — своя картинка).
4. «Динамика» → «+ Связь…» → «Случайно → Разброс», поднимите правую точку кривой.
5. Смотрите на образец мазка — он перерисовывается при каждой правке; на полосе пробы можно рисовать.
6. **«Экспорт в GrazySAI»** — кисть появилась в конце сетки рисовалки с подписью «Studio».
   Порисуйте, вернитесь в мастерскую, поправьте, снова «Экспорт» — кисть заменится.
7. Готово — «Сохранить как…» (`.gsbrush`) и отправьте файл. Получатель открывает его через
   «Файл → Открыть» или перетаскивает в окно GrazySAI.

## Из чего складывается кисть

| Раздел | Что даёт |
|---|---|
| Вид | поведение: карандаш — ровная краска; кисть и акварель — смешивание с холстом; ластик |
| Размер и плотность | диаметр, непрозрачность, нажим на них; жёсткость края; шаг отпечатков |
| Смешивание | у кисти, акварели, маркера: сколько цвета и прозрачности холста подхватывается |
| Отпечаток | круг или картинка; «Поворот», «Толщина» (сплющить), «по мазку» (поворот вдоль мазка), набор картинок «вразнобой» |
| Текстура | узор, который задерживает краску (тёмные места узора) |
| Динамика | связи «вход → кривая → параметр»: нажим, скорость, направление, путь, случайность → размер, плотность, поворот, толщина, разброс |
| Из плагина | своя динамика, написанная на Luau (docs/36-plugins.md) |

## Рецепты

| Кисть | Как |
|---|---|
| Каллиграфическое перо | отпечаток — круг, толщина 20 %, поворот 45° |
| Перо с сужением на концах | «Путь → Размер» с кривой, падающей к правому краю; масштаб 300–600 px |
| Брызги | отпечаток «брызги», шаг 0,5–1; «Случайно → Разброс» и «Случайно → Поворот» |
| Мел | отпечаток «мел», «Случайно → Поворот», плотность 70 % |
| Сухая кисть | вид «Кисть», текстура, «Скорость → Плотность» с падающей кривой |
| Штамп-узор | своя картинка, шаг 1,2–2 (отпечатки не сливаются) |

## Картинки для отпечатка

- PNG с прозрачностью: краска — непрозрачное; без прозрачности: краска — тёмное.
- Подойдут и кисти GIMP (`.gbr`, `.gih` — набор), Photoshop (`.abr`), отпечатки из кистей Krita и
  Clip Studio Paint (их можно просто открыть в GrazySAI).
- Большая сторона картинки сжимается до 512 px — больше кисти всё равно не нужно.

## Поделиться

Файл кисти — обычный zip, его можно отправить, выложить на сайт или в репозиторий. Внутри — только
настройки и картинки; программа проверяет их при открытии (размеры, имена без путей). Общего
каталога кистей пока нет; когда появится, он будет открытым репозиторием со списком файлов.
