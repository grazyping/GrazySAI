# Запись процесса рисования: устройство (`.gsrec`)

Запись — файл рядом с рисунком (`рисунок.sai2.gsrec`), который только дописывается в конец. Код —
`crates/paint-formats/src/record.rs`, меню и окно — `crates/paint-app/src/recording.rs`.

## Как пишется

- У каждого слоя есть номер `Layer::uid` (у копий слоя — свой). Счёт начинается с «секунды запуска × 2²⁰», поэтому номера не повторяются и между запусками; при продолжении записи слоям возвращаются номера из её последнего кадра (совпали глубина, вид и имя).
- Документ ведёт журнал изменений (`Document::journal`): какие плитки 256×256 какого слоя поменялись,
  какой слой поменялся целиком (вставка, удаление, кривые, маска), поменялся ли холст. Журнал
  заполняют шаги истории, отмена и повтор.
- Раз в кадр окна (не во время мазка) запись забирает журнал и пишет плитки, а затем кадр — дерево
  слоёв со свойствами. Сжатие и запись на диск — в отдельном потоке; после каждого кадра файл
  сбрасывается на диск, поэтому сбой программы теряет не больше одного шага.
- Каждый запуск записи начинается с полного кадра (холст и все слои целиком).

## Записи

Заголовок `GSREC\x01\0\0`, затем записи: вид (1 байт), длина (u32 LE), данные.

| Вид | Данные |
|---|---|
| `K` холст | ширина u32, высота u32, фон RGBA (A = 0 — прозрачный) |
| `C` слой очищен | номер слоя u64 |
| `T` плитка | номер слоя u64, x i32, y i32 (в плитках), флаг: 1 — дальше RGBA8 256×256 без предумножения, сжатый deflate; 0 — плитка пуста |
| `S` остановлено | пусто: запись остановил пользователь (при открытии рисунка она сама не продолжится) |
| `F` кадр (шаг) | время, мс от 1970 (u64), фон RGBA, число узлов u32, узлы: номер u64, глубина u8, флаги u8 (1 видим, 2 папка, 4 обтравка, 8 сквозная папка), непрозрачность u8, режим u8 (номер в `BlendMode::ALL`), длина имени u16, имя UTF-8 |

Оборванная последняя запись (сбой посреди записи) пропускается при чтении.

## Выгрузка

Плитки собираются по номерам слоёв; на каждом выбранном шаге из дерева кадра строится документ
(исключённые слои — невидимы), сводится, уменьшается (стороны чётные), получает водяной знак и
становится кадром APNG (крейт `png`, только изменившийся прямоугольник). Файл читается по одной записи, плитки распаковываются по мере нужды, видео пишется сразу на диск: 1500 мазков на холсте 3000×3000 (запись 95 МБ) выгружаются за ~35 с при ~110 МБ памяти. Шаги выбираются равномерно, чтобы
видео заняло заданное время; последний шаг всегда в видео. С паролем видео кладётся в zip с
шифрованием AES-256 (крейт `zip`).

Почему APNG, а не MP4: кодеки H.264 и подобные обременены патентами, а APNG открывается любым
браузером и пишется своим кодом. Позже можно добавить AV1 (`rav1e`).
