Записано 13 октября 2026. Копии лежат в `~/codex/refs/` (в проект не входят).

## Что есть в открытом доступе по SAI

Исходного кода PaintTool SAI в открытом доступе нет: программа закрытая. Поиск по GitHub даёт
в основном взломанные сборки под видом «SAI 2 Suite» — они не используются. Полезное:

| Что | Лицензия | Чем полезно |
|---|---|---|
| `photopea/SAI2-specification` | не указана | Неофициальное описание формата `.sai2` от автора Photopea: заголовок, оглавление, блок `layr`. Совпадает с тем, что выяснено здесь; упоминает блок `hist` и вариант метки `ver1` в заголовке. Про пиксели сказано только «плитки 256×256» — для слоёв это неверно (там блоки 32×32), сжатие не описано |
| `Wunkolo/libsai` | MIT | Чтение формата первой версии `.sai` (он зашифрован и устроен иначе). Пригодится, когда дойдёт до открытия старых файлов |
| `ametrien/Paint-Tool-SAI-pen-pressure-macOS-fix` | MIT | Как SAI получает нажим (WinTab) — справочно |
| `storytold/photocraft` | MIT или Apache-2.0 | Открытый редактор на Rust и egui: ввод с планшета, движок кисти, режимы наложения, PSD. Можно брать подходы и код с указанием авторства |

Из PhotoCraft взят подход к нажиму пера (см. ниже); код написан свой.

## Как нажим пера попадает в программу

| Система | Путь | Условие |
|---|---|---|
| Windows | Драйвер → Windows Ink → оконная библиотека winit превращает перо в «касание с силой» → egui отдаёт событие `Touch { force }` | В настройках драйвера XPPen для программы включён режим **Windows Ink** |
| Linux, X11 | Драйвер создаёт устройство с осью «Abs Pressure» → программа читает сырые события XInput 2 отдельным соединением | Планшет виден X-серверу |
| Linux, Wayland | Напрямую перо программам без протокола `zwp_tablet_v2` не отдаётся; окно открывается через XWayland, дальше как X11 | Есть XWayland (`DISPLAY`) |

Наклон и поворот пера winit на Windows отбрасывает; на Linux их можно читать так же, как нажим.
WinTab (способ самого SAI) в редакторе не подключён — он есть только в проверочной `pen-test`.

## Драйверы XPPen Artist 24 Pro

Скачаны с официальной страницы `xp-pen.com/download/artist-24-pro.html`, не устанавливались:

| Файл | Размер | SHA-256 (начало) |
|---|---|---|
| `XPPenLinux4.0.15-260422.deb` | 24,5 МБ | `414cc9ffb985…` |
| `XPPenWin_4.0.18.260720.zip` | 30,5 МБ | `468a29655851…` |

**Linux.** Пакет ставит программу `PenTablet` (Qt 5) в `/usr/lib/pentablet` с автозапуском и
правило udev: доступ всем к `/dev/uinput` и к USB-устройствам производителя `28bd`. Драйвера ядра
нет: программа сама читает планшет через libusb (отбирая его у ядра) и создаёт виртуальное
устройство ввода через uinput. Значит, приложения видят обычное устройство с нажимом — путь
XInput 2 для него подходит. Сценарий установки раздаёт права 0777 и 0666 на свои файлы.

**Windows.** Установщик Inno Setup 6.3; распаковать его без запуска не удалось (innoextract 1.9
эту версию не понимает), поэтому состав не проверен. По общим сведениям о драйверах этого
семейства он ставит службу, программу настройки и собственную `wintab32.dll`, а режим
Windows Ink включается галочкой в программе настройки — это не проверено по самому установщику.
