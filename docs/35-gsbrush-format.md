# Файл кисти GrazySAI: `.gsbrush` и набор `.gsbrushes`

Свой формат (с 1.0.29): кисть можно сохранить, передать и открыть у другого человека. Формат
открытый и простой — его можно собрать и без программы (zip и текстовый файл).

## Устройство

`.gsbrush` — zip-архив:

| Файл | Обязателен | Что внутри |
|---|---|---|
| `brush.txt` | да | настройки кисти, текст UTF-8 по строке `ключ=значение`; строки с `#` в начале — пояснения |
| `tip.png`, `tip.2.png`, `tip.3.png`… | нет | отпечаток и следующие картинки набора; краска — непрозрачное (или тёмное у картинки без прозрачности) |
| `texture.bmp` | нет | текстура кисти, BMP 8 бит серый: тёмное задерживает краску |
| `preview.png` | нет | образец мазка 256×64 для списков; программа его не читает |

`.gsbrushes` (набор) — тот же zip, кисти в папках `001/`, `002/`… с теми же файлами внутри.

## `brush.txt`

| Ключ | Значения | Что это |
|---|---|---|
| `format` | `1` | версия формата |
| `kind` | `pencil`, `airbrush`, `brush`, `water`, `marker`, `eraser`, `binary`, `bucket`, `gradient`, `selpen`, `selers` | вид инструмента (от вида зависят смешивание и поведение) |
| `name`, `extra` | текст | имя кисти и вторая строка в ячейке сетки |
| `size` | 0,1–5000 | диаметр, px |
| `min_size`, `size_by_pressure` | 0–1, `0`/`1` | доля размера при слабом нажиме; включён ли нажим на размер |
| `density`, `min_density`, `density_by_pressure` | 0–1, 0–1, `0`/`1` | плотность и её доля при слабом нажиме |
| `hardness` | 0, 0.5, 0.75, 0.9, 1 | жёсткость края (ступени SAI) |
| `spacing` | 0 или 0,01–10 | шаг отпечатков в долях диаметра; 0 — как в SAI |
| `sharpness`, `amplify`, `ver1_density` | 0–1, 0–1, `0`/`1` | тонкая настройка края и плотности, как в SAI |
| `blending`, `dilution`, `persistence`, `blur_pressure`, `blend_by_pressure` | 0–1… | смешивание с холстом (у Кисти, Акварели, Маркера) |
| `tip` | имя | отпечаток-картинка; при открытии берётся из `tip.png`, если он есть в архиве |
| `tip_angle`, `tip_ratio`, `tip_follow`, `tip_random` | −180…180, 0,01–1, `0`/`1`, `0`/`1` | поворот, толщина, поворот по мазку, набор вразнобой |
| `form`, `form_strength`, `form_scale` | имя, 0–1, 10–500 | «пятно» из папки SAI `blotmap` (по имени, внутрь файла не кладётся) |
| `bristle`, `hair_size`, `hair_min`, `randomize`, `direction` | имя, 0–1…, 0/1/2 | щетина из папки SAI `bristle` (по имени) |
| `texture`, `tex_strength`, `tex_scale`, `tex_min_density` | пусто, `paper`, `file:имя`; 0–1; 10–500; `0`/`1` | текстура: нет, бумага слоя, файл (`texture.bmp` из архива или узор SAI по имени) |

| `dyn.count`, `dyn.0`, `dyn.1`… | число; строка `вход выход масштаб x0 y0 x1 y1 x2 y2 x3 y3` | динамика: входы `pressure`, `speed`, `direction`, `distance`, `random`; выходы `size`, `density`, `angle`, `ratio`, `scatter`; масштаб — пиксели для скорости и пути; 4 точки кривой 0..1 |

Пример динамики: `dyn.0=distance size 400 0 1 0.33 0.7 0.67 0.4 1 0.05` — к 400-му пикселю пути
мазок сужается до 5 %.

Неизвестные ключи пропускаются, отсутствующие — берутся как у нового инструмента этого вида:
файл ранней версии откроется и в поздней.

## Безопасность при открытии

Файл кисти — чужие данные. Программа берёт из него только значения из таблицы (с границами),
картинки разбирает своим разборщиком PNG/BMP с ограничением размера, имена ресурсов с путями
(`/`, `\`, `..`) отбрасывает, в набор берёт не больше 256 кистей. Картинки кладутся в свою
папку настроек (`tips/`, `brushtex/`) под очищенными именами.
