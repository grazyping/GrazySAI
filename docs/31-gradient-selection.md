# Градиент, многоугольное лассо, расширение выделения

Сверено с живой SAI 2 (сборка 2017-01-19) на скрытом экране 15 октября 2026. Код —
`crates/paint-core/src/filters.rs` (`Gradient`, `gradient`), `crates/paint-core/src/selection.rs`
(`grow_by`, `polygon_aa`); тесты `linear_and_s_curve_match_sai`, `grow_by_cuts_corners_like_sai`.

## Градиент («Gradation»)

В SAI 2017 — вид инструмента, который ставится в пустую ячейку сетки (правый щелчок: Pencil,
AirBrush, Brush, Water Color, Eraser, Marker, Binary Pen, Bucket, Gradation, SelPen, SelErs).
Настройки: Form — Straight / Circle; Color Mode — FG Color to BG Color / FG Color to
Transparency; Reverse; S-Curve Gradation; кнопки OK и Cancel. После протяжки показываются линия
и кружок на конце, остальные панели неактивны до OK или Cancel.

Измерено (протяжка 800 px, зелёный канал 25 → 255, вид 100 %):

| Что | Результат |
|---|---|
| Прямой | доля `t` — проекция на отрезок, линейно; середина 140 (линейно — 140), у концов без смягчения (10 px — 28) |
| S-кривая | `3t² − 2t³`: 200 px — 61, 120 px — 39, середина 140 |
| Круг | `t` = расстояние от начала / длина протяжки: 60 px — 42 |
| В прозрачность | цвет основной, непрозрачность `1 − t` (над белым — те же значения, что к белому фоновому) |
| За концами | 0 и 1 |

## Многоугольное лассо

У лассо в SAI 2017 настройки «Selection Mode: Freeform / Polygonal» и «Anti-Aliasing».
Многоугольник: щелчок ставит вершину, к курсору тянется линия; Enter или двойной щелчок —
закрыть; Esc — отменить весь многоугольник; Backspace вершину не убирает. Без сглаживания у нас
точка выделена, если покрыта больше чем наполовину.

## Расширить и сузить выделение

Меню Selection: «Dilate Selection…», «Erode Selection…», «Dilate Selection 1px», «Erode
Selection 1px». Окно — ползунок Width 1–25, «Update Preview while Changing Slider», Preview.
Прямоугольник, расширенный на 25 px: стороны сдвинулись на 25, углы срезаны под 45° по 12 px.
Это шаги по очереди квадратом 3×3 и крестом, первый — квадрат (13 квадратов и 12 крестов:
`|dx| + |dy| ≤ 38`). Так и сделано; сужение — те же шаги с наименьшим значением.

## Двоичное перо и свои инструменты сетки (0.8.16)

Меню SAI 2017 по правому щелчку на инструменте: Cancel, Duplicate, Delete, Property; окно
«Custom Tool Property» — Tool Name (около 8 знаков), Additional Name (строка под именем),
Shortcut Key. Сделано всё, кроме своей клавиши инструмента.

Binary Pen в SAI 2017: размер 1, мин. размер 0 %, Opacity 0–255, Algorithm «Accurate / Simple (No
Prs.)», Color Picker «Normal / Layer ARGB». Линии размера 1 у SAI — ступени без полутонов, но не
простое правило: при наклоне 0,2 — ровно по 5 точек без перекрытия, при 0,4 — по 3 с перекрытием
через ряд. У SOsai пока круг радиуса `size/2` (не меньше 0,5) без сглаживания по центрам
пикселей; точное правило — по коду SAI позже.

## Обводка слоя (0.8.17)

«Layer → Outline…» SAI 2017: Width 1–25, Position Inside / Center / Outside, «Apply to Canvas
Edges too», предпросмотр. Замеры на живой SAI:

- Залитый прямоугольник, 25 px: снаружи — кольцо +25 со срезом углов 12 (как расширение
  выделения); внутри — полоса 25 внутрь, углы прямые; по центру — 12 наружу (срез 6) и 13 внутрь.
- Мягкий мазок аэрографа, 7 px, синий поверх красного: доля обводки = расширенная на `o`
  непрозрачность минус суженная на `i` (снаружи (7, 0), внутри (0, 7), по центру (3, 4)),
  основной цвет кладётся поверх слоя обычным наложением; расхождение модели с SAI по столбцу —
  до 1,3–1,6 уровня.
- Без «Apply to Canvas Edges too» за краем холста — непрозрачно (у края полосы нет).

Код — `Document::outline`, общая для выделения и обводки `selection::morph`; тест
`outline_matches_sai_shapes`.

## Меню «Слой» (0.8.18)

По живой SAI 2017: «Merge Visible Layers» сводит все видимые слои (и папки) в новый слой со
следующим номером на месте самого верхнего видимого, скрытые остаются, новый выбран; «Rotate
Layer 90deg. CW/CCW» поворачивает рисунок слоя вокруг середины его рисунка (не холста);
«Layer Property…» — только имя слоя. Код — `Document::merge_visible`, `rotate_layer`; тест
`rotate_layer_and_merge_visible_like_sai`.
