# Текстовые слои

Разобраны по файлу пользователя `буковки2.sai2` (SAI 2 сборки 2017-01-19, шесть текстовых
слоёв разными шрифтами) и сведённой картинке, которую сохранил сам образец. Код —
`crates/paint-formats/src/sai2_text.rs`, тест `text_layers_round_trip` (файл пользователя в
репозиторий не входит, тест без него пропускается).

## В файле

Описание слоя `layr` с видом `text` и областью `0,0,0,0`; пикселей (`lpix`) нет. Содержимое —
блок оглавления `text` с номером слоя (по коду записи и чтения SAI):

| Что | Формат |
|---|---|
| метка | `text` |
| точка привязки | f64 x, f64 y (с 4-го байта) — левый верх строки на холсте |
| флаги слоя | два байта (поля 0x789, 0x78a): бит 0 первого — вертикальный текст (по образцу `НовыйХолст1.sai2`); затем `01 64` |
| `tvec` | 32 байта: матрица 2×2 из f64 (у всех образцов единичная) |
| `data` | u32 число шрифтов; на шрифт u16 длина и имя в UTF-16 с нулём на конце («Noto Sans Mono Black» — семейство с начертанием); вложенный `text` — поток u32; в конце u32 0 |
| поток | символ — его код; старший байт 1 — номер шрифта, 2 — стиль, 3 — размер в px, 5 — размер в сотых px, 4 — цвет 0xRRGGBB |
| конец блока | u32 0 |

Атрибут пишется только там, где меняется (начальные значения — нули): поэтому у чёрного текста
нет тега цвета, у стиля 0 — тега стиля. Атрибуты могут меняться внутри строки. Пустой слой —
`data` длины 0. Стиль (тег 2) — биты: 4 — жирный, 8 — курсив (образец с жирным, курсивом и
вертикальным текстом от пользователя).

## Как рисуется

- Шрифт ищется в системе по имени: в Linux — `fc-match`, в Windows — по таблицам имён шрифтов в
  `Windows\Fonts` и шрифтах пользователя.
- Строка: верх строки — точка привязки, базовая линия ниже на подъём шрифта; символы идут по
  ширинам шрифта; точка строки переводится на холст матрицей `tvec`.
- Символов, которых нет в шрифте, — запасным шрифтом системы (как у образца: в «Noto Serif
  Georgian» нет цифр и кириллицы). У образца запасной шрифт крупнее — тут расхождение остаётся.
- Жирный и курсив SAI рисует не отдельным начертанием, а из обычного (GDI): курсив — наклон
  0,209 (x += 0,209·подъём над базовой линией), жирный — без утолщения в контуре, но шаг символа
  больше на размер/12 (подобрано по SAI под Wine: ширины строк 98–356 против 98–355 px).
- Вертикальный текст — строка, повёрнутая на 90° по часовой стрелке: (u, v) → (−v, u)
  относительно точки привязки; следующие строки — левее.
- Сверка со сведённой картинкой образца: средняя разница 0,11 из 255 по всему холсту (без
  текста было 0,35).

## Инструмент «Текст» (0.8.12; на холсте — с 0.8.45)

С 0.8.45 — как в SAI 2017 (сверено вживую): щелчок сразу вставляет слой «Текст» над текущим,
набор идёт на холсте в рамке с курсором (`caret_positions` повторяет раскладку `render`),
настройки — на панели инструмента (вертикально, цвет, размер, начертание, список шрифтов) и
применяются к надписи сразу. Пока идёт набор, слой меняется без записи в историю
(`insert_layer_quiet`, `set_vector_quiet`); при завершении живая правка снимается и
записывается одним шагом; пустая новая надпись исчезает. Ниже — прежний способ с окном.


Кнопка «T» на панели инструментов. Щелчок по холсту — новая надпись в этой точке (новый слой
«Текст» над текущим), щелчок при выбранном текстовом слое — правка. Окно: многострочный текст,
шрифт из системных (`fc-list` в Linux, таблицы имён в Windows; поиск по имени), размер в px;
цвет — основной цвет панели. OK — одна запись отмены. Блок пишется в той же раскладке, что у
образца (`to_bytes`; по всем шести слоям образца разбор и запись дают те же байты). Жирный,
курсив и вертикальный текст (0.8.13) — галочки в том же окне, биты — по образцу.
Если правка не меняет ни текст, ни шрифт, ни размер, слой остаётся как был (в том числе с
разными атрибутами внутри строки); иначе надпись становится одним отрезком.

## Список шрифтов

SAI берёт шрифты через `EnumFontFamiliesExW` (кодировка 1 — DEFAULT_CHARSET), пропускает имена
на «@» и растровые шрифты, а имя — семейство из таблицы `name` (nameID 1), обрезанное до 31
знака UTF-16. Если имени шрифта нет в этом списке, SAI при открытии файла пишет «Внутренняя
ошибка». GrazySAI строит список так же (`font_index`: ttf-parser, nameID 1, обрезка до 31 знака,
только контурные шрифты): под Wine совпадает 1635 из 1640 имён, нет только встроенных шрифтов
Wine (Marlett, Symbol, Tahoma, Webdings, Wingdings).

## Запись

Блок `text` пишется обратно байт в байт, описание слоя — с видом `text` и областью нулей, как у
образца. Текстовые слои, как контур и фигуры, кистью не правятся и не двигаются; «Слой →
Растеризовать слой» делает обычный слой.

## Линейки перспективы

Слои видов `pers` и `grid` (линейки и сетки перспективы, появились в SAI после сборки 2017-01-19)
не рисуются, но блоки сохраняются как были. Образца файла с ними нет.
