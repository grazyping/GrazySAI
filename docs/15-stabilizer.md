# Стабилизатор

14 октября 2026, по коду `sai2.bak` (своими словами).

| Что делает |
|---|
| Уровень из списка «Сглаживание»: 1–16 или S-1…S-7 (коды `0x81`–`0x87`) |
| Начало штриха: кольца на 16 значений по x, y и нажиму заполняются первой точкой (N копий; у S-k — 15 и k+1) |
| Точка: положить в кольцо и взять среднее последних N; у S-k — среднее 15, затем среднее k+1 таких средних |
| Отрыв пера: последняя сырая точка проводится через фильтр ещё N раз (у S-k — 15·(k+1)), линия доходит до места отрыва |

Сделано так же в `paint-core/src/stabilizer.rs` (тесты `stabilizer_*`), в окне — список 0…15 и
S-1…S-7.

Не проверено: соответствие числа в списке и N (взято N = число; у образца 0 и 1 дают одно и то
же — среднее по одной точке).

Сверка с живой SAI по клину (`14-virtual-pen.md`): сглаживание на связь «место → нажим» на ровном
клине не влияет — среднее сдвигает положение и нажим одинаково. Оставшиеся 0,6–0,8 px разницы
похожи на опережение нажима на 2–3 пакета; возможно, это цепочка Wine → XWayland, а не SAI.
Проверить на настоящем планшете.
