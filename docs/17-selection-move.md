# Выделение и перемещение

14 октября 2026. Код — `paint-core/src/selection.rs`, `document.rs`; окно — `paint-app/src/main.rs`.

## Выделение

Маска 0..1 поверх холста с плавным краем. Пустая маска — выделения нет, рисовать можно везде.

| Что | Как |
|---|---|
| Прямоугольник (M) | Протянуть; края по целым пикселям; щелчок без протяжки снимает выделение |
| Лассо (L) | Обвести; край сглажен (точная доля площади пикселя) |
| Волшебная палочка (W) | Щелчок: связная по четырём соседям область текущего слоя, где каналы RGBA отличаются от точки щелчка не больше допуска (0–255, по умолчанию 10) |
| Режимы | Без клавиш — заменить; Shift — добавить; Alt — вычесть; Shift+Alt — пересечь (как в SAI) |
| Перо и ластик выделения | «Выд.К.» и «Выд.Л.» в сетке кистей: мазок добавляется к выделению или вычитается из него; во время мазка путь виден полупрозрачной полосой; по умолчанию без нажима, 10 px |
| По непрозрачности слоя | Ctrl + щелчок по миниатюре слоя — заменить; Shift+Ctrl — добавить; Ctrl+Alt — вычесть; Shift+Ctrl+Alt — пересечь (доля выделения = альфа слоя) |
| Ctrl+A / Ctrl+D | Выделить всё / снять выделение |
| Ctrl+H | Показать или скрыть границу |
| Меню «Выделение» | Инвертировать, расширить или сузить на 1 px |

Выделение ограничивает всё рисование: покрытие штриха умножается на долю выделения (у
смешивающих кистей — и краска, и размытие Акварели). Delete при выделении очищает только
выделенное. Каждое изменение выделения — отдельная запись истории (Ctrl+Z).

Граница показана «бегущими муравьями» по порогу половины выделения.

## Перемещение

Инструмент «Перемещение», Ctrl + перетаскивание любым инструментом или Alt+стрелки (на 1 px,
с Shift — на 10). Без выделения двигается весь текущий слой; с выделением выделенная часть
вырезается и кладётся поверх остального на новом месте, выделение едет вместе с ней. Во время
перетаскивания показ идёт без записи в историю; по окончании — одна запись (отмена возвращает и
пиксели, и выделение).

## Трансформация (Ctrl+T)

Рамка вокруг выделенного (или всего содержимого слоя) с восемью ручками: углы и середины
сторон меняют размер (противоположная сторона на месте), протяжка внутри рамки — сдвиг,
снаружи — поворот вокруг центра рамки. Enter или повторное Ctrl+T — применить, Esc — отменить;
Ctrl+Z во время трансформации тоже отменяет её. Перед сохранением, сменой слоя и действиями со
слоями трансформация применяется.

Пиксели считаются выборкой по матрице теми же ядрами, что у пересэмплирования образца
(`resample::affine`, `docs/12-resampling.md`); способ выбирается в панели (ближайший, билинейный,
бикубический, Ланцош 2 и 3). За краем картинки берётся прозрачность, поэтому края при повороте не
«размазываются». Во время протяжки показ идёт билинейным способом, по отпусканию — выбранным.
Выделение трансформируется вместе с пикселями. Вся трансформация — одна запись истории.

**Свободная деформация**: Ctrl + перетаскивание угла переводит рамку в свободный режим, и дальше
каждый угол двигается отдельно; протяжка внутри двигает всю рамку.

**Режимы и «Перспектива» (0.8.15)**, как в панели SAI 2017: «Свободно» (всё, деформация —
Ctrl + угол), «Изменить размер» (без поворота), «Деформация» (углы без Ctrl), «Поворот» (стороны и
углы поворачивают). Ползунок «Перспектива» 0–100. Сверено с живой SAI 2017: сетка 6×6, правый
верхний угол утянут; где линии сетки пересекают столбец — при 0 точно билинейное отображение, при
100 — проективное (`square_to_quad`), между ними точка — смесь двух в доле `P/100`: замеры при 0,
25, 50, 75, 100 совпали с расчётом до 0,5 px экрана при 50 % (`Warp::Quad`, тест
`free_deform_blends_bilinear_and_perspective_like_sai`). По умолчанию 0 — как у SAI; раньше
SOsai всегда деформировал перспективой. Обратное отображение для смеси — метод Ньютона от
перспективного ответа.

Проверено виртуальным пером: протяжка угла меняет размер, протяжка снаружи по дуге в 20°
поворачивает полосу на 19,7°.
