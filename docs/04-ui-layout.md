# Раскладка главного окна образца

По снимку экрана пользователя от 13 октября 2026 (`docs/ref/sai2-main-window.png`, окно 1280×995). Описано, что где стоит, — как ориентир для своего интерфейса.

## Общая схема

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ Меню: Файл  Правка  Холст  Слой  Выделение  Линейка  Фильтр  Вид  Окно  Помощь │
├──────────────┬──────────────────────────────────────────────┬─────────────────┤
│ Цвет         │ Быстрая панель                               │ Навигатор       │
│ (круг + ква- │──────────────────────────────────────────────│ масштаб, угол   │
│ драт)        │                                              │─────────────────│
│──────────────│                                              │ Эффекты слоя    │
│ Общие        │                                              │ Текстура        │
│ инструменты  │              Холст на сером поле             │ Режим, непрозр. │
│ + два цвета  │                                              │ Замки, флажки   │
│──────────────│                                              │─────────────────│
│ Кисти слоя   │                                              │ Кнопки слоёв    │
│──────────────│                                              │─────────────────│
│ Параметры    │                                              │ Список слоёв    │
│ кисти        │                                              │                 │
│──────────────│                                              │                 │
│ Сетка        │──────────────────────────────────────────────│                 │
│ размеров     │ Вкладки открытых холстов                     │                 │
├──────────────┴──────────────────────────────────────────────┴─────────────────┤
│ Строка состояния: «Памяти занято 7% (9%)», «Место диска 26%»                   │
└───────────────────────────────────────────────────────────────────────────────┘
```

Левая колонка около 235 px, правая около 180 px, остальное — холст.

## Левая колонка, сверху вниз

1. **Переключатели вида панели цвета** — пять значков: круг, ползунки RGB, HSV, смеситель, образцы.
2. **Круг цвета**: кольцо тона, внутри квадрат насыщенности и яркости; маркеры на кольце и в квадрате.
3. **Общие инструменты**, две строки по пять: выделение прямоугольником, лассо, палочка, фигуры,
   текст; перемещение, масштаб, поворот вида, рука, пипетка. Справа — квадраты основного и
   фонового цвета со стрелкой обмена и квадрат «прозрачный цвет».
4. **Кисти текущего слоя** — сетка ячеек 4 в ряд с названием и значком. На снимке выбран слой
   контура, поэтому набор векторный: Pen, Eraser, Weight, Color, Edit, Prssure, SelPen, SelErs.
5. **Параметры кисти**: «Режим» (список), «Жесткость» (пять кнопок-профилей края), «Размер»
   (множитель шкалы `x0.1` и значение), «Минимальный» (%), «Плотн.» (ползунок 0–100),
   «Мин. Плотн.» (%); сворачиваемые разделы «Текстура», «Векторизация», «Разное»; флажки
   «Размер» и «Плотн.» — что управляется нажимом.
6. **Сетка размеров кисти**, 5 в ряд, кружок и число: 0.6, 0.8, 1, 1.3, 1.6, 2, 2.5, 3, 3.5, 4,
   5, 6, 7, 8, 9, 10, 12, 14, 16, 20, 25, 30, 35, 40, 50, 60, 70, 80, 100, 120, 160, 200, 250,
   300, 350 и дальше.

## Быстрая панель над холстом, слева направо

Отмена, повтор; две кнопки выделения (снять, инвертировать — неактивны); «Выделение» с глазом
(показать или скрыть); масштаб `100%` со списком и кнопками «−», «+», «сброс»; угол `+0.0°` со
списком и кнопками поворота против часовой, по часовой, сброс; зеркало по горизонтали;
«Сглаживание» со списком (стабилизатор, значение 3); кнопка режима прямой линии.

## Правая колонка, сверху вниз

1. **Навигатор**: уменьшенный холст; под ним ползунки «Масштаб 100%» и «Угол +0°», у каждого три кнопки.
2. **Эффекты слоя** (сворачивается): «Эффект» (список, «[ Нет ]»), «Ширина», «Сила».
3. **Текстура** (сворачивается): «Выбрать» (список), «Сила», «Масштаб», флажок «Применить к вектору».
4. **Режим** наложения (список, «Обычный») и **Непроз.** (ползунок, 100%).
5. **Замок** — четыре кнопки: прозрачность, рисование, перемещение, всё.
6. Флажки **«Прикрепление»** (обтравочная группа) и **«Источник выбора»**.
7. **Кнопки слоёв**, два ряда: новый слой, новый слой контура, новая папка, линейка перспективы,
   маска; перенести вниз, слить, очистить, удалить; применить маску.
8. **Список слоёв**: у строки глаз, отметка, миниатюра, имя, режим и непрозрачность мелким
   текстом («Вектор1 / Обычный / 100%»); выбранная строка подсвечена.

## Низ

Вкладки открытых холстов (значок, имя файла, масштаб). Строка состояния с двумя полосами:
занятая память и место на диске под историю.

## Замечания для своей реализации

- Набор кистей в левой колонке зависит от вида текущего слоя (обычный, контур, фигуры).
- Все числовые поля — ползунок, по которому можно тянуть, с числом внутри.
- Интерфейс плотный, шрифт мелкий (около 11 px), серое поле вокруг холста.

## Как это сделано у нас (14.10.2026)

`crates/paint-app` повторяет эту раскладку: меню с буквами-ускорителями; слева круг цвета
(кольцо тона и квадрат насыщенности/яркости), общие инструменты с основным и фоновым цветом,
сетка кистей (Каранд., Аэрогр., Кисть, Акварель, Маркер, Ластик, Выд.К., Выд.Л.), параметры
кисти полосками-ползунками, пять ступеней жёсткости значками-профилями, разделы «Форма»,
«Текстура», «Разное» (в нём Sharpness), сетка размеров кружками; над холстом быстрая панель;
справа навигатор с рамкой видимой части, масштаб и угол, «Эффекты слоя», «Текстура», режим,
непрозрачность, замки, «Прикрепление», кнопки слоёв и список слоёв с миниатюрами; внизу
вкладка холста и «Памяти занято». Оформление — `src/sai_ui.rs`, снимок — `ref/paint-rs-ui.png`.

Операции со слоями — с отменой и повтором: новый слой и папка, копия, удаление, очистка (Delete),
«Перенести на нижний» (F), «Слить с нижним» (Ctrl+E), выше и ниже. То, чего ещё нет в ядре
(выделение, поворот вида, маски, слои контура, эффекты, текстуры), показано неактивным — как неактивные пункты у образца. Клавиши:
`[` и `]` — размер кисти по сетке, Ctrl+Z/Ctrl+Y, Ctrl+«+»/«−», Alt — пипетка, пробел — рука.
