# Форма и текстура кисти

Разделы «Форма» (Form) и «Текстура» (Texture) инструмента — как в SAI 2 сборки 2017-01-19:
устройство прочитано в коде образца и сверено с живой SAI (`crates/paint-core/src/stroke.rs`,
`dab.rs`; тест `tests/grain_live.rs`).

## Что в образце

- **Форма**: «[ Simple Circle ]» или файл из `blotmap` (55 штук), сила (Intensity, 0–100, по
  умолчанию 100), масштаб (Scale, по умолчанию 100 %). Щетина из `bristle` — отдельный вид
  формы (раздел «Щетина» ниже).
- **Текстура**: «[ No Texture ]», «[ Layer Paper ]» (бумага текущего слоя) или файл из
  `brushtex` (31 штука), сила (100), «Affect by MinDens» (включён), масштаб (100 %).
- Обе текстуры привязаны к холсту (к началу слоя), выборка — та же, что у бумаги слоя
  (`docs/24-paper.md`): значение точки BMP — номер цвета.

## Текстура

Отпечаток считает покрытие края (0…0x4000), потом из каждой точки вычитается
`v·s`, где `v = 0x4000 - ((t·257/2 + 1)/2)` по значению текстуры `t` (0–255), а `s` — сила в
1/256 (`(int)(сила·256)`), с насыщением в ноль. Светлая точка текстуры (t = 255) не трогает
покрытие, тёмная (t = 0) при силе 100 убирает его целиком. Непрозрачность отпечатка и
накопление в мазке — как без текстуры.

- «Affect by MinDens»: сила × `(мин. плотность · 32 · (1 - нажим)² + 1) · clamp(размер, 1, 5) / 5`,
  не больше 255. При размере от 5 px и нулевой мин. плотности — просто сила.
- Бумага слоя: значения берутся обратными — образец переворачивает каждые 4 байта как одно
  32-битное число (`-x`), то есть почти `255 - t`.

## Форма «пятно»

- Край отпечатка — конус от центра: `f = max(0, 1 - d / край)`, профиль `(f³ - f)·a + f`
  (выпуклость `a` только у очень тонких кистей). Ширина края — `1.5·радиус + мин. край` на
  **любой** ступени жёсткости: ветка формы не задаёт мягкость, и только так совпадает с живой
  SAI (при мягкости по ступени жёсткие линии выходили вдвое тоньше).
- Порог: `покрытие = clamp(профиль·B - t·A - C, 0, 1)`, где по ступени жёсткости 0…4
  B = 1.263, 2.0, 2.571, 4.0, 6.0; C = 0.158, 0.273, 0.429, 0.5, 0.5;
  A = B·D·сила/255, D = 0.667, 0.727, 0.889, 1.0, 1.333 (таблицы образца). Жёсткость меняет
  только резкость пятна.
- Непрозрачность отпечатка подбирается по линейной таблице края (как у образца); у самой
  жёсткой ступени крупной кисти отдельная подобранная ветка с формой не включается.

## Сверка

Карандаш 20 px мышью, горизонтальные линии на холсте 600×500 в SAI 2017 и в SOsai, доля краски
по синему каналу в полосе ±14 px:

| Ряд | Разница |
|---|---|
| текстура Canvas 100 | 1,5 % |
| текстура Canvas 56 | 1,2 % |
| Blots 100, самая жёсткая | 0,07 % |
| Blots 100, самая мягкая | 1,3 % |
| Blots 100, средняя | 0,4 % |

Тест ищет файлы SAI в `SOSAI_SAI_DIR` (папка с `blotmap` и `brushtex`); без неё пропускается.
Файлы узоров — собственность автора SAI, в репозиторий не входят.

## В SOsai

- Разделы «Форма» и «Текстура» у всех кистей; списки — из папки SAI. Папка та же, что у бумаги
  слоя: можно указать `papertex` или саму папку SAI, соседние `blotmap` и `brushtex` найдутся.
- Настройки сохраняются у каждого инструмента между запусками.
- Работает и у смешивающих кистей (Кисть, Акварель, Маркер) — сверено пока только Карандашом.

## Щетина (0.8.27)

В списке «Form» SAI 2017 после пятен через разделитель — файлы `bristle` (BMP 63×63, 24 или 32
бита; `res_bristle`, вид формы 3). Настройки: Hair Size (50), Hair Min (0 %), Randomize (0 %),
Direction (None, Auto, Pen Direction).

По коду: волоски — чёрные пиксели картинки (не больше 63), SAI даёт волоску смещение
(−y, x) с разбросом `(rand/32767 − 0,5)·√(1 − …)·Randomize`; волосок ставится в
точку штриха + смещение, повёрнутое по направлению и умноженное на радиус; направление (Auto) —
по ходу штриха, поворот сглаживается средним по 16 последним; если волосок
поворачивает на 20° и больше, на этом отрезке он не красит; отрезок
волоска рисуется цепочкой круглых отпечатков. Размеры подобраны по живой SAI (`Bristle.bmp`, размер 50):
ширина полосы 47 px, волосок ≈5 px — у SOsai диаметр волоска 0,2·Hair Size·размер, разлёт
1,13·радиус, волоски жёсткие при любой жёсткости кисти; ширина 46 px, концы с теми же прядями.
Разброс — свой генератор (у SAI `rand()`, совпасть точно не может); «по перу» без наклона пера —
как «нет». Сверка на глаз — `tests/bristle_look.rs` (нужны `SOSAI_PAPERTEX` и
`SOSAI_BRISTLE_OUT`).
