# План работ

Цель: свой графический редактор на Rust по образцу PaintTool SAI 2, для личного пользования.
Работает на Linux и Windows, планшет XPPen Artist 24 Pro, обязательно открывает файлы `.sai2`.
Образец изучается по поведению, интерфейсу и файлам; код пишется свой.

## Устройство

| Часть | Что делает | Состояние |
|---|---|---|
| `crates/paint-core` | Пиксели, плитки, дерево слоёв с папками и обтравкой, 20 режимов наложения, кисть, штрих (в том числе «живой» — с показом по ходу), стабилизатор, отмена, сведение | есть, 12 тестов |
| `crates/paint-cli` | Рендер без окна для проверки ядра (`cargo run -p paint-cli -- out.png`) | есть |
| `crates/paint-formats` | Чтение `.sai2`: заголовок, оглавление, описания слоёв и пиксели растровых слоёв (6 тестов на образцах). Не читаются папки как иерархия, маски, контурные и текстовые слои. Дальше — свой формат, PSD | в работе |
| `crates/pen-test` | Проверка пера и рисования: окно и журнал событий. Windows — режимы Windows Ink и WinTab (`dist/pen-test.zip`, ждёт проверки на планшете); Linux — X11 с XInput 2, в Wayland через XWayland (`dist/pen-test-linux/`, мышью проверено) | есть |
| `crates/paint-app` | Окно редактора (egui) в раскладке и оформлении образца (`04-ui-layout.md`): холст с масштабом и сдвигом, панели цвета, кисти и слоёв, дерево папок, рисование пером и ластиком со сглаживанием, отмена, открытие `.sai2`, сохранение PNG. Сборки: `dist/paint-app-linux/`, `dist/paint-app-windows.zip`; запуск `paint-rs [файл]`. Нажим пера подключён (Windows Ink; на Linux — XInput 2 через XWayland), на живом планшете не проверен | первая версия |

Ядро не знает про окно и планшет: всё, что можно, проверяется тестами и картинками.

## Этапы

1. **Ядро** — сделано 13.10.2026: холст из плиток 64×64, 15 бит на канал, 16 режимов наложения,
   круглая кисть (размер и плотность по давлению, жёсткость), ластик, «сохранять непрозрачность»,
   стабилизатор, отмена и повтор по плиткам, PNG. Картинка: `docs/demo-01.png`.
2. **Чтение `.sai2`** — растровые слои читаются (`docs/03-sai2-format.md`); способ сжатия выяснен
   разбором оригинала в Ghidra (рабочая папка `~/codex/sai2-analysis`, в проект не входит).
   Папки и обтравка читаются; сведение сверяется с картинкой `intg` из самого файла (пробные
   файлы — 100%, настоящий рисунок — 56% точно, средняя разница 1,4 из 255). Осталось: бумага слоёв,
   маски, точные формулы режимов, особые виды слоёв.
3. **Окно и планшет** — первая версия окна есть (13.10.2026). Осталось: нажим пера (по журналам
   `pen-test`), поворот и зеркало вида, навигатор, меню, диалоги файлов, свой формат сохранения.
4. **Кисти как в образце** — круглый отпечаток сделан по разбору образца и сверен с работающим
   образцом (`docs/08-brush-verification.md`): от 20 px совпадает в пределах 1–3 уровней из 255.
   Не совпадают тонкие кисти 1–5 px, узкий край и жёсткая линия. Осталось: формы (`blotmap`),
   щетина (`bristle`), текстура (`brushtex`), смешивание с холстом, режимы рисования.
5. **Слои полностью** — папки, маски, обтравочные группы, оставшиеся режимы, бумага и кайма.
6. **Выделения, заливка, градиент, трансформация.**
7. **PSD, свой формат, настройки, горячие клавиши.**
8. **Контурные слои, фигуры, текст, перспектива** — самое объёмное, в конце.

Требования к поведению (клавиши, щелчки по слоям, пометки в заголовке, полный список команд образца)
собраны в `docs/07-sai2-reference.md`; там же — какие из них уже выполнены.

## Принятые решения

- Пиксель: RGBA с предумноженной альфой, 15 бит на канал — без потерь при многократном наложении.
- Штрих копится в отдельной маске (максимум покрытия), на слой переносится целиком: краска внутри
  одного штриха не темнеет сверх плотности, отмена — одна запись.
- Режимы наложения — по общепринятым формулам; фирменные режимы образца добавляются после сверки.
